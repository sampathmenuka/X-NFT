# X-NFT — Curated NFT Marketplace

A responsive, multi-page front-end for **X-NFT**, a fictional curator-led NFT house where artists release verified drops and collectors bid, buy, and vote on what comes next. It has a dark neon style and is built with plain HTML, CSS, and JavaScript on top of Bootstrap 5.

## Pages

| Page | What's on it |
| --- | --- |
| **Home** | Hero with a live auction countdown, trending drops, "How it works", stats, and a call to action |
| **Explore** | NFT gallery with live search, category filters, and likes |
| **About** | Story, mission and vision, core values, stats, and team |
| **RoadMap** | Timeline of phases and progress bars |
| **Contact** | Contact form with validation, contact details, and FAQ |
| **Join** | Sign-up form with a password strength meter and wallet options |

## Highlights

- **Mobile-first:** swipeable card rows, a full-screen mobile menu, large tap targets, and support for notched iPhones.
- **Interactive:** scroll-in animations, counting stats, a live countdown, toast messages, and inline form validation.
- **Accessible:** semantic markup, keyboard focus outlines, ARIA labels, and respect for the "reduce motion" setting.
- **No build step:** one stylesheet ([css/style.css](css/style.css)) and one script ([js/script.js](js/script.js)).

## Run it

Open `index.html` in a browser, or serve the folder with a local server (for example, VS Code Live Server on port 5501).

> This is a front-end demo. Forms, bids, and wallet connections are simulated and show confirmation messages; no data is sent anywhere.
